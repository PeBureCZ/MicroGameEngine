MicroGameEngine is a personal project created to improve my C++ skills while, more importantly, exploring different approaches to software architecture and engine design. It serves as a playground for experimenting with new ideas, testing architectural patterns, and gaining hands-on experience through practical development.
This is intended to be a long-term learning project rather than a production-ready framework. As a result, it currently does not include features aimed at simplifying installation or distribution, such as CMake support or other tooling typically expected from a publicly released project. The primary goal is learning and experimentation, with convenience and broader usability taking a back seat—for now.
